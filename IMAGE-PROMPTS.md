# Guru's — Image Prompts (17 images for you to generate)

Each prompt below is complete. Copy the **Prompt** block as-is into your image generator (ChatGPT / DALL·E, Midjourney, Gemini, Firefly, Ideogram, Leonardo).

**Save every finished file into:** `E:\guru kitchen\site\src\assets\img\` using the exact filename shown. The website picks it up automatically.

**You only need to generate the food images.** Everything else (decorations, spice and tandoor banners, grocery photo, social-share image) I'm sourcing from free-licence stock sites, your current website, or making myself. See the last section.

### How to read each entry
- **Final file:** what the website needs. "Cutout" means a PNG with a **transparent background**, just the plate with no box around it.
- **Generate at:** the size or aspect setting to pick in your tool.
- **After generating:** generators can't make transparent backgrounds, so every food prompt asks for a pure white background. Remove it with remove.bg, Photoroom, Canva ("BG Remover") or Photoshop ("Remove Background"), then export as PNG.
- **Avoid:** paste into the "negative prompt" field if your tool has one. Midjourney users can use the `--no` line.
